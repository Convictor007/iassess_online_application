Technology Stack

  • Frontend: React 19 + TypeScript + Tailwind CSS
  • Build: Vite 5
  • Backend: Vercel Serverless Functions
  • Database: Neon PostgreSQL
  • File Storage: Vercel Blob (private)
  • Email: Nodemailer via Gmail SMTP
  • Deployment: Vercel

Transaction Types

  • Assessment:
  •   - Transfer of Ownership (With Title)
  •   - Transfer of Ownership (Handog Titulo)
  •   - Appraisal of Land (First Time)
  • Certification:
  •   - Certified True Copy of TD (PHP 50/cop)
  •   - Certificate of Landholdings (PHP 50/cop)

Key Components

  • 12 steps in the wizard flow
  • 8+ React components
  • 7 API endpoints
  • Dynamic branching based on user selection
  • Payment module built but not yet active
  • Mobile app schema ready (3-step approval)

Flow Summary

  • 1. Home - Landing page + tracking
  • 2. Privacy Notice - RA 10173 consent
  • 3. Transaction Select - Assessment or Certification
  • 4. Type Selection - Sub-type + fees
  • 5. Requirements - Document checklist
  • 6. Submission Method - Walk-in or Online
  • 7. Document Upload - If online (conditional)
  • 8. Property Info - Owner & land details
  • 9. Requestor Info - Contact details
  • 10. Summary - Review before submit
  • 11. Submit - Save + email notification
  • 12. Confirmation - Transaction code issued
