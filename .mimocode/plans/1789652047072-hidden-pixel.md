# Plan: Mobile App Application Detail Improvements

## Changes to `iassess_mobile/app/assessor/section/application-detail.tsx`

### 1. Remove Upload Button (lines 631-638)
- Delete the `TouchableOpacity` with the Upload icon from the Documents card header
- Simplify `docHeader` to just show the title (no need for `justifyContent: 'space-between'`)
- Keep `handleUploadDocument` function and `DocumentPicker` import in case needed later (or remove entirely)

### 2. Remove Approval Workflow Section (lines 707-785)
- Delete the entire Approval Workflow card including the `handleStartWorkflow`, `handleApproveStep`, `handleRejectStep`, and `openRejectModal` functions
- Delete the Reject Modal (lines 922-960) and related state (`showRejectModal`, `rejectStepId`, `rejectReason`)
- Remove the Assign Modal if it's only used for approval workflow (lines 962-1007) — actually keep it since it's a separate feature
- Remove `approveApprovalStep`, `rejectApprovalStep`, `createApprovalSteps` from the API PATCH handler if they're no longer needed on mobile

### 3. Add Document Preview/View Button
- Add a "View" button (TouchableOpacity) next to each document row's delete button
- On press, generate a signed download URL by calling the online app's API: `GET https://iassess.vercel.app/api/documents/view?pathname={doc.blob_pathname}`
- Use `expo-web-browser` (or `Linking.openURL`) to open the URL in a browser/in-app browser
- Add import for `expo-web-browser` or `expo-linking`
- Show a loading indicator while the signed URL is being fetched

### 4. Delete Confirmation Modal
- Replace the current `Alert.alert()` with a custom `<Modal>` component (matching the style of the Note/Reject/Assign modals)
- Add state: `showDeleteModal`, `deleteDocId`, `deleteDocName`
- Show the document name in the confirmation message
- Cancel and Delete buttons styled like the existing modals

### 6. Fix Certification Price (₱0.00)
- **Root cause**: Old application records in the database have `fee: 0` in the `certifications` table because they were inserted before the fee was set to 100
- **Fix**: Update the display to use a fallback when fee is 0:
  ```tsx
  const certFee = c.fee > 0 ? c.fee : (CERT_DEFAULT_FEES[c.cert_type] ?? 0);
  ```
- Add `CERT_DEFAULT_FEES` constant:
  ```ts
  const CERT_DEFAULT_FEES: Record<string, number> = {
    certified_true_copy: 100,
    cert_land_holdings: 100,
    tax_declaration: 100,
  };
  ```
- Display: `{c.copies}x — ₱{(certFee * c.copies).toFixed(2)}`
