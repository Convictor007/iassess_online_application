# Plan: Fix Document Viewer Not Showing Content

## Root Cause

Documents uploaded from the **web app** (`iassess_online_application`) use `access: 'private'` in Vercel Blob with the web app's `BLOB_READ_WRITE_TOKEN` (`87379ccc...`). The **mobile app** (`iassess_mobile`) has `BLOB_READ_WRITE_TOKEN='your-vercel-blob-token-here'` — a **placeholder**, not configured.

When the mobile app calls `getDownloadUrl(file_url)`, it fails silently because:
1. The mobile app has no valid Blob token
2. Even if it did, it would reference a different store than the web app's

The web app already has a working endpoint at `/api/documents/view?url=<blob_url>` that generates signed URLs using its own token.

## Fix: Two changes needed

### 1. Mobile app `documents+api.ts` — GET handler
**File:** `iassess_mobile/app/api/documents+api.ts`

Instead of calling `getDocumentDownloadUrl(doc.file_url)` (which fails), call the **web app's** endpoint:

```ts
const WEB_APP_URL = process.env.EXPO_PUBLIC_V3_API_URL || 'https://iassess.vercel.app';

// In the GET handler, after fetching the doc from DB:
const viewRes = await fetch(`${WEB_APP_URL}/api/documents/view?url=${encodeURIComponent(doc.file_url)}`);
const viewJson = await viewRes.json();
if (viewJson.success && viewJson.url) {
  return Response.json({ success: true, data: { url: viewJson.url, mime_type: doc.mime_type } });
}
```

Remove the `getDocumentDownloadUrl` import (no longer needed).

### 2. Mobile app `document-storage.ts` — remove unused function
**File:** `iassess_mobile/lib/document-storage.ts`

Remove the `getDocumentDownloadUrl` function and the `getDownloadUrl` import since we're using the web app's endpoint instead.

## Files to modify
